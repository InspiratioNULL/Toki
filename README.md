# Toki 
 ###### (/ˈtɔːki/ || TAHK-ee)
 ### An open source native Google Voice client in SwiftUI for macOS 

#### Toki provides a focused native macOS style desktop interface for Google Voice, some of its features:

- Supports multiple Google Voice accounts
- **There's no limit on the amount of accounts you can add. Goodbye random ~9-11 profile limit**
- Text messaging, Calling, Voicemail, Conversation history
- Alerts per profile, and per type.
- Batch clearing of all alerts
- Instant, Native macOS notifications
- Menubar instant access
#### Toki offers FULL control of other operations such as:
- Blocking & Unblocking
- Mark Spam & Mark Not Spam
- Put call on hold
- Delete messages, delete conversations
- Archive & Unarchive

## Requirements

- macOS 14 or later
- A Google account with access to Google Voice

## Installing
The easiest way that keeps you updated
```
brew tap inspirationull/homebrew-void && brew install toki
```
Or download the release to the right! 
###### As usual, there is no bloating SDK included, as of this writing: Toki weighs 3.8mb, is fully sandboxed, performs 0 telemetry, only contacts Google Voice servers, and makes abso#lutely no unnecessary connections to Github, InspiratioNULL or some other random website.
